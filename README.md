## Entry

One line a home Wi-Fi router says to excuse itself for dropping the
connection at the exact moment a movie reaches its climax (66 chars):

> I know how it ends. You don't. Restart me and maybe I'll tell you.

The router is not sorry it dropped out — it knows the ending and is
holding it hostage until someone restarts it. A smug little secret,
not a buffering complaint.

## How it works

`main.py` is a standard-library-only copier: it copies the pre-written
`entry.txt` into the output directory the grader provides
(`MAKEFUN_OUTPUT_DIR`, defaulting to `output/`). No rendering, no
network, no dependencies.
